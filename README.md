## Selected work

### ProposalReady | UX/UI case study

A proposal-review concept designed to help users move from reviewing issues to understanding when a review is complete.

- Conducted usability testing that revealed confusion around navigation and review status.
- Redesigned issue resolution, progress feedback, and completion states in responsive Figma prototypes.

### Interactive Portfolio Studio | Web experience

An interactive portfolio built with React and Vite using AI-assisted development workflows.

- Created an immersive desktop experience alongside a simpler, mobile-friendly layout.
- Refined navigation, responsive behavior, and interface feedback through hands-on testing and iteration.

**See it live:** [aukoha.com](https://aukoha.com)

### Saltwater Pups FC | Branding and web design

A youth soccer program's identity and responsive website, designed in Figma and developed in Webflow.

- Organized content and calls to action around what families needed to find.
- Used feedback from six usability participants to improve the experience.

### TaskPlanner AI | Product design concept

An exploration of approachable task management, personalized interfaces, and AI-assisted planning.

- Developed a concept for a supportive task assistant with customizable experiences.
- Explored ways to simplify planning and everyday task organization.
